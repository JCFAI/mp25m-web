# MP25M_S — Hoja rápida

## ¿Qué quiero hacer?

| Necesidad | Ir a |
|---|---|
| Buscar o consultar una persona | Personas |
| Buscar o consultar una organización | Organizaciones |
| Ver la estructura territorial | Nodos |
| Consultar capacidades o saberes | Habilidades |
| Consultar o registrar un eje de trabajo | Temas |
| Proponer o seguir una coordinación entre actores | Articulaciones |
| Proponer o seguir una iniciativa con ejecución | Proyectos |

## Antes de crear algo

Buscar primero si ya existe.

Personas y Organizaciones son registros canónicos: si el actor ya está
registrado, se reutiliza. Evitar duplicados permite conservar correctamente
sus vínculos, antecedentes y participación territorial.

## Articulaciones

Usarlas para coordinar actores alrededor de un propósito.

Al trabajar con una Articulación revisar:

1. objetivo;
2. estado;
3. responsable;
4. participantes;
5. historial;
6. seguimiento.

Los campos necesarios para guardar una operación aparecen identificados con
`(Obligatorio)` en la propia pantalla.

## Proyectos

Usarlos cuando existe una iniciativa que requiere ejecución, participantes y
entregables.

Una propuesta puede comenzar sin representar todavía un compromiso
institucional definitivo.

## Estados, responsables e historial

El estado indica en qué situación está un registro.

El responsable identifica quién tiene a cargo el próximo paso.

Los motivos, cambios y seguimientos permiten reconstruir qué ocurrió y por
qué. No reemplazar esa trazabilidad con información informal fuera del
sistema cuando el dato corresponde a MP25M.

## Permisos

No todas las personas ven o pueden modificar lo mismo.

Las posibilidades de consulta y gestión dependen del rol y del alcance
territorial. Si una acción no está disponible, no intentar resolverlo creando
otro registro o duplicando información.

## Ayuda

El botón `Ver recorrido` abre nuevamente el tutorial contextual disponible en
la pantalla actual.

MP25M_S contiene la operación inicial. Las funciones anunciadas para
`MP25M_M` todavía no forman parte de esta etapa del piloto.
