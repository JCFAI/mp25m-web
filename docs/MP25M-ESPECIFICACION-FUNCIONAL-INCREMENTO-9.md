# MP25M — Incremento 9A: Proyectos de ejecución

## Propósito

Incorporar el primer registro operativo de proyectos para las ejecuciones que fueron acordadas luego de una articulación.

## Regla principal

Una oportunidad, una articulación y un proyecto son registros distintos. Un proyecto sólo puede crearse mediante una decisión humana explícita desde una articulación cerrada con resultado. No se genera automáticamente al cerrar una articulación.

## Alcance

- Alta de un proyecto en borrador desde una articulación cerrada con resultado.
- Título, objetivo, responsable interno y estado del proyecto.
- Seguimiento manual mediante novedades.
- Bitácora de cambios de estado y auditoría.
- Navegación y listado de proyectos en el panel.

## Controles

- Una articulación puede originar un solo proyecto de ejecución.
- Activar un proyecto exige un responsable interno.
- Completar un proyecto exige un resumen final.
- Todos los cambios deben incluir un motivo.
- Sólo usuarios con permiso operativo sobre la oportunidad de origen pueden modificar el proyecto.

## Fuera de alcance

No incorpora presupuestos, cobros, pagos, distribución de fondos, agenda, notificaciones, automatizaciones, asignación automática de participantes ni exposición de datos de contacto.
