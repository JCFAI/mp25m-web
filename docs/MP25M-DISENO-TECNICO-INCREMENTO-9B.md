# MP25M — Diseño técnico Incremento 9B

## Modelo

Se agregan `project_participants` y `project_deliverables`, con vistas de lectura en `mp25m_api`. Las funciones de escritura aplican el permiso operativo de la oportunidad de origen, validan los datos mínimos y registran auditoría.

## Evidencia

Esta etapa conserva una referencia textual o enlace de evidencia; no incorpora carga de archivos. Una entrega en estado `delivered` o `accepted` exige resumen de resultado y referencia de evidencia.

## Límite

La relación de participantes se propone desde la articulación fuente sólo para facilitar la decisión humana. No crea membresías, disponibilidad, agenda, pagos ni contactos automáticos.
